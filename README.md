# Vinayak Kesarwani — Portfolio

A responsive personal portfolio with an interactive particle portrait, project gallery, hanging project ID card, and contact section.

## Run locally

Open `index.html` in a browser, or serve this directory with:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The ID card uses `id-card-motion.html`. The site loads Three.js and fonts from public CDNs; the particle portrait and ID card artwork are embedded in the HTML files.
